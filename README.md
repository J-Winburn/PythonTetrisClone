This is a Tetris Clone! Built with the help of "Making Games With Python & Pygame" by Al Sweigart

CONTROLS: use arrow keys to move pieces left and right
The down key makes pieces move faster
the up key will rotate the pieces

DOWNLOAD ON MAC: 
download the game files directly here on github. When trying to open on mac you may experience security issues
to open the game follow the stepes below

Right click file and select "Open" 
if blocked by security go to System Settings > Privacy and Security > "Open Anyway"
